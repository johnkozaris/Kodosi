## Kodosi로 할 수 있는 것

### 어떤 에이전트가 나를 기다리는지 확인하기

Claude Code, Codex 같은 코딩 에이전트는 작업 도중 자주 멈추고 입력을 기다려요. Kodosi는 모든
컴퓨터의 터미널을 한 창에 모아 두고, 각 터미널에서 에이전트가 작업 중인지, 내 입력을
기다리는지, 완료되었는지, 실패했는지 보여 줘요. 알림은 휴대폰을 포함해 지금 사용 중인 기기로
전달돼요. 에이전트는 각자의 CLI를 통해 기존 설정과 계정 그대로 직접 실행돼요.

### 무엇이 나를 기다리는지 묻기

Dosi는 다른 에이전트들을 관리해 주는 에이전트예요. 터미널들을 확인해 나를 기다리는 일을 요약해
주고, 내가 어떻게 할지 결정하면 대신 터미널에 답해요.

문서를 동시에 함께 편집할 수 있어요.

### 함께 일하기

실행 중인 터미널을 친구와 공유하거나, 사람과 에이전트가 함께 쓰는 프로젝트에 터미널, 채팅,
작업을 한데 모을 수 있어요.

<p align="center"><img src="../media/project.webp" width="900" alt="공유 터미널과 사람 및 에이전트 간의 대화가 있는 프로젝트."></p>

### 비공개, 그리고 오픈 소스

터미널과 프로젝트에는 양자 내성 종단 간 암호화가 적용되어 있어 백엔드가 내용을 읽을 수 없어요.
Kodosi는 오픈 소스이며, 서버를 직접 운영할 수도 있어요.

## Kodosi 받기

| 플랫폼 | 요구 사항 | 설치 |
| --- | --- | --- |
| Mac | Apple silicon, macOS 26 이상 | 디스크 이미지를 열고 Kodosi를 응용 프로그램 폴더로 끌어다 놓거나, `brew install --cask johnkozaris/tap/kodosi`를 실행하세요. 앱은 자동으로 업데이트돼요. |
| Linux | x86-64, Ubuntu 24.04 또는 Debian 13 이상 | Debian 패키지를 설치하세요. Kodosi apt 저장소가 자동으로 추가되어 시스템 업데이트 시 Kodosi도 최신 상태로 유지돼요. [최신 릴리스](https://github.com/johnkozaris/Kodosi/releases/latest)에는 Arch 패키지와 포터블 압축 파일도 포함되어 있어요. |
| Windows | x64, Windows 11 24H2 이상 | 설치 프로그램을 처음 열기 전에 관리자 권한으로 [Kodosi 인증서](https://updates.kodosi.com/windows/Kodosi.cer)를 로컬 컴퓨터 › 신뢰할 수 있는 사람에 추가하세요. 앱은 자동으로 업데이트돼요. |
| Android | ARM64, Android 15 이상 | 기기에서 APK를 다운로드해 열고, Android가 확인을 요청하면 설치를 허용하세요. 업데이트도 같은 방법으로 설치해요. |
| iPhone과 iPad | iOS 26 이상 | [iPhone과 iPad](../../clients/ios/README.md)(영어)용으로 Kodosi를 소스에서 직접 빌드하세요. |

설치를 마쳤다면 [시작하기](GETTING_STARTED.md)를 읽어 보세요.

## 라이선스

Kodosi는 [Apache License 2.0](../../LICENSE) 라이선스를 따라요. Kodosi 이름과 로고는 이
라이선스에 포함되지 않으므로, 사용 규칙은 [상표](../../TRADEMARKS.md)(영어)를 참고하세요.
Kodosi는 [Ghostty](https://ghostty.org), Rust, Swift, Qt, ASP.NET Core로 만들어졌어요. 자세한
저작권 표시는 [서드파티 고지](../../terminal/ghostty/THIRD_PARTY_NOTICES.md)(영어)와
[미디어 출처](../media/README.md)(영어)에서 확인할 수 있어요.
