## Kodosi로 할 수 있는 것

### 어떤 에이전트가 나를 기다리는지 보기

Claude Code, Codex 같은 코딩 에이전트는 작업을 멈추고 나를 기다려요. Kodosi는 모든 컴퓨터의
터미널을 한 창에 모아 두고, 각 터미널은 에이전트가 작업 중인지, 내 답변을 기다리는지,
끝났는지, 실패했는지 보여 줘요. 자리를 비웠을 때는 휴대폰에서도 알림을 받아요. 에이전트는
자기 설정과 로그인 그대로 평소처럼 실행돼요.

### 무엇이 나를 기다리는지 묻기

Dosi는 내 에이전트들을 위한 에이전트예요. 터미널을 읽고 무엇이 나를 기다리는지 알려 주고,
내가 고르면 나 대신 터미널에 답해요.

함께 편집해요.

### 함께 일하기

실행 중인 터미널을 친구에게 주거나, 사람과 그 에이전트들을 위한 프로젝트에 터미널, 대화,
작업을 모을 수 있어요.

<p align="center"><img src="../media/project.webp" width="900" alt="공유 터미널과 사람과 에이전트의 대화가 있는 프로젝트."></p>

### 비공개, 그리고 오픈 소스

터미널과 프로젝트는 양자 내성 암호로 종단 간 암호화되므로 서비스는 내용을 읽을 수 없어요.
Kodosi는 오픈 소스이고, 서비스를 직접 운영할 수도 있어요.
[보안](SECURITY.md) · [직접 호스팅하기](../SELF-HOSTING.md)(영어)

## Kodosi 받기

| | 요구 사항 | 설치 |
| --- | --- | --- |
| **Mac** | Apple silicon, macOS 26 이상 | 디스크 이미지를 열고 Kodosi를 응용 프로그램으로 옮기거나 `brew install --cask johnkozaris/tap/kodosi`를 실행하세요. 앱은 스스로 업데이트돼요. |
| **Linux** | x86-64, Ubuntu 24.04 또는 Debian 13 이상 | Debian 패키지를 설치하세요. Kodosi apt 저장소가 추가되므로 시스템을 업데이트하면 Kodosi도 업데이트돼요. [릴리스](https://github.com/johnkozaris/Kodosi/releases/latest)에는 Arch 패키지와 포터블 압축 파일도 있어요. |
| **Windows** | x64, Windows 11 24H2 이상 | 다운로드한 파일을 처음 열기 전에 관리자로 [Kodosi 인증서](https://updates.kodosi.com/windows/Kodosi.cer)를 로컬 컴퓨터 › 신뢰할 수 있는 사람에 추가하세요. 앱은 스스로 업데이트돼요. |
| **Android** | ARM64, Android 15 이상 | 기기에서 APK를 내려받아 열고, Android가 물으면 설치를 허용하세요. 새 릴리스도 같은 방법으로 설치해요. |
| **iPhone과 iPad** | iOS 26 이상 | [iPhone이나 iPad](../../clients/ios/README.md)용으로 Kodosi를 빌드하세요. |

그다음 [시작하기](GETTING_STARTED.md)를 따라 하세요.
