# はじめに

[English](../GETTING_STARTED.md) · [Deutsch](../de/GETTING_STARTED.md) · [Ελληνικά](../el/GETTING_STARTED.md) · [Español](../es/GETTING_STARTED.md) · [Français](../fr/GETTING_STARTED.md) · [Italiano](../it/GETTING_STARTED.md) · **日本語** · [한국어](../ko/GETTING_STARTED.md) · [简体中文](../zh-Hans/GETTING_STARTED.md)

お使いのコンピュータ向けに [Kodosi をダウンロード](README.md#kodosi-を入手)してください。以下のショートカットは macOS のキー表記を使っています。Linux と Windows では、特に記載がない限り ⌘ を Ctrl+Shift に読み替えてください。

## 1. サインイン

Kodosi を開き、サイドバー下部の **サインイン** をクリックします。ブラウザが開くので、そこからサインインしてください。ターミナルから `kodosi auth login` を実行すればデバイスコードが発行され、任意のブラウザに入力してサインインすることもできます。

サインインしなくてもローカルのターミナルは利用できます。ほかのコンピュータの接続、フレンドの追加、プロジェクトの利用にはサインインが必要です。

## 2. エージェントを起動する

⌘N を押す（または **新しいターミナル** をクリックする）とランチャーが開きます。エージェントとフォルダを選び、必要に応じてアカウント、モデル、推論レベルを指定して最初のプロンプトを入力し、Return キーを押します。Kodosi が新しいシェルに起動コマンドを入力します。

<p align="center"><img src="../media/launcher.webp" width="580" alt="Claude Code、フォルダ、最初のプロンプトを設定したランチャー画面。"></p>

まだインストールされていないエージェントには、ランチャー上にインストールコマンドが表示されます。

### ターミナルをすばやく開く

- ⌘D（Linux と Windows では Ctrl+Shift+O）を押すと、選択中のターミナルと同じフォルダで通常のシェルを開きます。
- ⌘T（Ctrl+Shift+T）を押すと、選択中のターミナルと同じエージェント、アカウント、設定で新しいターミナルを開きます。
- サイドバーでフォルダの横にある `+` ボタンをクリックすると、そのフォルダで実行中のエージェントを同じアカウントと設定のまま、もう 1 つのターミナルで起動します（エージェントが動いていない場合は通常のシェルを開きます）。
- シェルプロンプトで待機しているターミナルでは、ヘッダーのアクションボタン（2 本のスライダー）をクリックすると、インストール済みの任意のエージェントを前回の設定で起動できます。

### キーボードショートカット

ショートカットは Ghostty のデフォルトに準拠しており、**設定 › ショートカット** でカスタマイズできます。

- ⌘1 から ⌘9（Linux と Windows では Alt+1 から Alt+9）: 並び順でターミナルを切り替えます。
- ⌥⌘ + 矢印キー（Ctrl+Alt + 矢印キー）: 隣のターミナルに移動します。
- ⌘W: 選択中のターミナルを閉じます。
- ⌘↑ と ⌘↓: zsh や新しい bash（macOS 標準の bash 3.2 を除く）でシェルプロンプト間を移動します。

### 権限、詳細度、高速モード

- エージェントはデフォルトで制限なしで起動するため、確認を求めずにファイル編集やコマンド実行を行います。Antigravity CLI だけは例外で、独自の自動モードで起動し、取り消せない操作の前に確認を求めます。操作の前に確認させるには、モデル選択の次にある **その他** から **確認** を選びます。
- **その他** では、Claude Code、Codex、Copilot CLI、Antigravity CLI の出力の詳細度も設定できます（デフォルトは **簡潔** です）。Copilot CLI は保存された設定からしか詳細度を読み取らないため、Copilot CLI が簡潔モードで動いている間だけ Kodosi が Copilot の設定を一時的に更新し、終了後に元へ戻します。
- Claude Code と Codex では高速モード（コストは上がりますが応答が速くなります）に対応しており、モデルや推論レベルと並んだトグルで切り替えられます。高速モードはその回の起動にのみ適用され、次回はオフに戻ります。

### アカウントと実行中の切り替え

- 新しいアカウントを追加すると、`~/.claude-work` のように独立した設定フォルダが作成されます。`alias cw='CLAUDE_CONFIG_DIR=~/.claude-work claude'` のようにシェルのエイリアスで定義されたアカウントも Kodosi が自動検出します。
- エージェントの実行中でも、ヘッダーのアクションボタン（2 本のスライダー）から再起動せずにモデル、推論レベル、高速モード、および対応エージェントでは権限を切り替えられます。現在のターンが終わり次第、Kodosi がエージェント自身のスラッシュコマンドを送信します。なお、Claude Code では変更したモデル、推論レベル、高速モードが次回以降のセッションにも引き継がれます。

### リンク、画像、worktree、テーマ

リンクを今使っているデバイスの既定のブラウザで開くには、⌘ を押しながらクリックします（Linux と Windows では Ctrl+クリック）。実行中のプログラムがマウス入力を捕捉している場合は、Shift も同時に押してください。iPhone ではタップで開きます（プログラムがマウスを捕捉している間は無効です）。Kodosi は別のアプリへリンクを渡す前に確認を求め、実行可能ファイルや、リモートコンピュータから来たリンクのうちローカルファイルパスと `localhost` の URL は開かないようにブロックします。

スクリーンショットや画像をエージェントに渡すには、⌘V（Linux と Windows では Ctrl+Shift+V、iPhone ではペースト）で貼り付けます。Kodosi が画像をターミナルのホストコンピュータに保存してファイルパスを貼り付けるため、エージェントがその画像を添付できます。リモートターミナルの場合はアップロードの進捗も表示されます。なお、エージェント独自の貼り付けショートカット（Claude Code の Ctrl+V など）は、引き続きエージェントが動いているコンピュータ側のクリップボードを読み取ります。

エージェントに Git リポジトリの独立したコピーを渡すには、サイドバーでリポジトリのフォルダにポインタを合わせ、ブランチボタンをクリックしてブランチ名を入力します。Kodosi は新しい Git worktree でターミナルを開き、変更が何もなければターミナルを閉じた際に自動で削除します。worktree の保存場所は **設定 › ターミナル** で変更できます。

各ターミナルの外観（ライト／ダーク）は、どのデバイスから表示していても、ホストコンピュータ上の Kodosi の外観に従います。ターミナル内のプログラムにはテーマ変更が通知されるため、`/theme` を Auto に設定した Claude Code などのツールは自動で適応します。Kodosi 本体がライトモードのときもターミナルをダークのままにしたい場合は、**設定 › ターミナル** で **ターミナルを常にダークに保つ** をオンにしてください。

### 閉じる、終了、macOS のアクセス権

すべてのターミナルは、ホストコンピュータ上で動く本物のシェルです。**最小化** はターミナルを非表示にしたまま動かし続け、**閉じる** はシェルとその子プロセスを終了します。アプリのウインドウを閉じても、Kodosi とターミナルはメニューバーやシステムトレイで動き続けます（システムトレイのない Linux デスクトップでは、ウインドウを閉じると Kodosi も終了します）。ウインドウを閉じたときの動作は **設定** で変更できます。

Kodosi を終了するとターミナルは停止し、その画面状態がローカルのコンピュータだけに保存されます（サーバーには保存されません）。次に Kodosi を開くと、元のフォルダ、プロジェクト、ステージ上の位置でターミナルが再び開き、新しいプロンプトの上に以前の画面とスクロールバックが表示されます（Windows では上にスクロールして確認してください）。Claude Code、Codex、Copilot CLI は会話を自動で再開し、macOS と Linux では選択していたモデル、推論レベル、高速モード、権限、詳細度も引き継ぎます。どの会話だったかを Kodosi が特定できない場合は、エージェントが会話一覧を表示するのでそこから選べます。

macOS では、ほかのターミナルアプリと同様に、Kodosi 内のプログラムは Kodosi に付与された macOS のアクセス権を継承します。別のアプリを変更しようとしたプログラムを macOS がブロックした場合は、**App管理**（**設定 › 一般** から開けます）で Kodosi を有効にしてください。アプリ操作や画面キャプチャを行うツール向けに、**デバイスの制御とデータへのアクセス**（macOS 27 より前は **アクセシビリティ**）や **画面収録とシステムオーディオ録音** も同じ場所から許可できます。

## 3. どのエージェントが対応を待っているかを見る

各ターミナルのアイコンに、現在の状態が表示されます。

| 表示 | 意味 |
| --- | --- |
| アイコンのまわりを回る暖かい光 | 作業中（進捗率が報告されている場合は、埋まっていくリングで割合を表示）。 |
| 手、疑問符、または鍵 | 承認、回答、またはサインインを待機中。 |
| 緑のチェック | 完了。 |
| 黄色の警告マーク | 失敗。 |

チェックと警告マークは、いずれかのデバイスでそのターミナルを開くと消えます。

ターミナルが待機状態になったとき、完了したとき、または失敗したとき、Kodosi は今あなたが使っているデバイスに一度だけ通知します。

- Kodosi にフォーカスがあるときは、状態アイコンだけが表示されます。
- コンピュータで別のアプリを使っているときは、そのコンピュータにデスクトップ通知が表示されます。
- どのコンピュータからも離れているときは、スマートフォンにプッシュ通知が届きます。コンピュータを離れた時点で未確認の待機中ターミナルがある場合も、そのタイミングでスマートフォンへ転送されます。

通知音が鳴るのは待機中のターミナルだけです。通知のミュートはデバイスごとに **設定** から切り替えられます。プログラムは [Program Status Protocol](https://www.superlogical.com/rex/docs/build/program-status) または標準的なターミナル進捗シーケンスで状態を報告します。状態を報告しないプログラムにはアイコン表示が出ません。

### チャット表示

Claude Code を実行中のターミナルや、Kodosi から起動した Codex・Copilot CLI のターミナルでは、ヘッダーに **チャット** 表示も用意されています。チャットにはあなたのメッセージ、エージェントの返信やツール実行履歴、未回答の質問がクリックできるボタン付きで表示されます。チャット画面から直接返信したりエージェントを止めたりでき、質問中に自由入力でメッセージを送れば、代わりに何をしてほしいかを伝えられます。チャットで行った操作は、裏側のターミナルにもそのまま反映されます。

## 4. エージェントがキャンバスに表示するものを見る

エージェントは HTML ページ、Markdown、画像、PDF、Office ドキュメント、スプレッドシート、プレゼンテーション、実行中のウェブアプリをターミナル横の **キャンバス** に表示したり、共有ブラウザを操作したりできます。デフォルトでは、そのターミナルを見ている間にエージェントが何かを表示・更新すると自動でキャンバスが開きます（手動で閉じた場合を除く）。自分で開くときだけにするには、**設定 › 一般** で **キャンバスを自動で開く** をオフにします。

Claude Code、Copilot CLI、Antigravity CLI は手動で起動してもキャンバスの使い方を知っています。Codex、Cursor、OpenCode は Kodosi から起動した場合に使い方を知っています（OpenCode は macOS と Linux のみ）。そのほかのエージェントには、`kodosi skill canvas` を実行するよう伝えてください。

キャンバスにコンテンツがあると、ターミナルのヘッダーに **ファイル** と **ブラウザ** のボタンが追加され、新着があるときは銅色の点が付きます。

- どちらかのボタンをクリックすると、ターミナルの隣にキャンバスが開きます。
- **広く表示** をクリックすると、キャンバスがステージ全体を使い、ターミナルは隅に小さく収まります。
- パネルを閉じるにはボタン上の `×` を、再び開くには `+` をクリックします。
- アクションメニューの **ブラウザを開く** から手動でブラウザを開いたり、**ファイルを追加…**（またはキャンバスへのドラッグ＆ドロップ）でファイルを追加したりできます。追加したファイルはターミナルのフォルダにもコピーされます。
- iPhone ではキャンバスボタンがターミナルバーにあり、新規表示や更新があると **開く** ボタン付きのバナーで通知されます。

### ライブドキュメントとページ

- ドキュメント（`.docx`）、スプレッドシート（`.xlsx`）、プレゼンテーション（`.pptx`）、PDF、テキストファイルはライブで同期されます。ディスク上の通常のファイルのまま、あなた、ターミナルを共有しているメンバー、エージェントが同時に編集できます。ドキュメントに変更履歴がある場合は、ツールバーに変更の承認・却下ボタンが表示されます。**設定 › ドキュメント** では、各ビューアのオン／オフ、ページ表示とフロー表示の切り替え、ダークモード時のダークページ表示を設定できます。
- キャンバス上の HTML ページはネットワークアクセスのない完全オフライン環境で動作します。ページ、ドキュメント、シート、スライド、PDF 内のリンクは、ターミナルのリンクと同じ安全ルールであなたのブラウザに開きます（編集可能なビューでは ⌘+クリックまたは Ctrl+クリック、それ以外では通常クリック、iPhone ではタップ）。同じファイル内のスライドやセルへの内部リンクはそのまま該当箇所へジャンプします。
- ページやドキュメント内のテキストを選択して **これについて質問** をクリックすると、ファイル名と選択したテキストがターミナルへそのまま入力され、続けて質問を書けます。
- ファイルタブを右クリック（モバイルでは長押し）すると、コピーを保存したり、そのファイルや全ファイルをキャンバスから外したり、ファイルをホストコンピュータのゴミ箱へ移動したりできます。

### 共有ブラウザ

- 共有ブラウザでは、通常のブラウザと同じようにクリックや入力ができます。エージェントにも同じページとログイン状態が見えており、あなたがブラウザを使ったことは、エージェントが次に実行するブラウザコマンドの出力で伝えられます。
- 10 分間操作がないとブラウザはスリープし、あなたかエージェントが再び使うと最後に開いていたページを復元します。そのコンピュータで初めて共有ブラウザを開くときは、Kodosi Browser が自動でダウンロードされるため、少し時間がかかります。
- プライベートなターミナルで普段のブラウザのログイン情報を再利用したい場合は、**設定 › ブラウザ** で対象ブラウザの横にある **コピー** をクリックします。コピーした情報を消すには **削除** を、プライベートなターミナルのログイン情報とサイトデータをすべて消去するには **すべて削除** をクリックしてください。macOS で Safari などブラウザのデータへのアクセスが OS により制限されている場合は、そのブラウザの横にある **許可…** をクリックしてフルディスクアクセスを許可します。
- ターミナルにアクセスできる人は全員そのキャンバスを見て共有ブラウザを使えます。ターミナルを閉じるとキャンバスはクリアされ、共有ターミナル用のブラウザログイン情報も破棄されます。

## 5. Dosi に聞く

Dosi は、ほかのエージェントをまとめるためのあなたのエージェントです。サイドバー下部の Dosi の顔をクリックするか、⌘J を押して開きます。Dosi は Claude Code または Codex 上で動作し、使用するエージェント、アカウント、モデル、推論レベルは **設定 › Dosi** で設定できます。

何に対応が必要か Dosi に尋ねたり、作業を任せたりできます。Dosi はターミナルやプロジェクトの状況を確認し、プロンプトに回答したり、ターミナルの起動・終了やメッセージの中継を行ったりします。判断が必要な場面では、選択肢のボタンとあわせて自分の言葉で返信できる入力欄が表示されます。

Dosi との会話はすべてのデバイスで同期されます。iPhone や iPad では、入力欄のすぐ上でメッセージを送るコンピュータの Dosi を選べます（デフォルトでは最後に返信したコンピュータが選ばれます）。オフラインのコンピュータ宛てのメッセージはオンラインに戻るまでキューに入り、**送信しない** で取り消せます。

Dosi の顔の横にあるステータス行には、作業中、返信あり、質問への回答待ちなどの状態が表示されます。そのコンピュータにエージェントがまだインストールされていない場合は **Dosi を設定** と表示され、クリックすると **設定 › Dosi** が開きます。特定のコンピュータで Dosi を無効にしたい場合は、**設定 › Dosi** で **Dosi を使う** をオフにしてください。

## 6. ほかのコンピュータやスマートフォンを追加する

新しいコンピュータで同じアカウントにサインインすると、確認コードが表示され、既存のデバイスに承認を求める通知が届きます。承認済みのコンピュータで **承認** をクリックしてコードを入力するか、承認済みのスマートフォンでコードをスキャンしてください。

スマートフォンやタブレットはスキャン 1 回で追加できます。承認済みのコンピュータで **設定** を開き、**デバイスを追加** の下にある **コードを表示** をクリックして、新しいデバイスでスキャンします。承認が完了すると、すべてのコンピュータのターミナルがどのデバイスからも表示されます。

### ほかのコンピュータでターミナルを起動する

別のコンピュータでターミナルを起動するには、ランチャーバーの右側で対象のコンピュータを選びます。フォルダメニューにそのコンピュータの最近使ったフォルダが表示され、**フォルダを選択…** からホームディレクトリ内を参照できます。iPhone と iPad では **ターミナル** 内、または特定のコンピュータの横にある `+` をタップします。対象のコンピュータでは Kodosi を開いておくか、ターミナルで `kodosi host` を実行しておく必要があります。

自分のデバイス 2 台が直接通信できる環境では、ターミナルやブラウザの通信がピアツーピアでやり取りされ、遅延が小さくなります。ローカルネットワーク上では macOS、iOS、Android が一度だけローカルネットワーク権限の確認を表示します。許可しない場合、通信は中継サーバー経由にフォールバックします。

### リカバリーキー

**設定** でリカバリーキーを作成し、安全な場所に保管してください。万が一すべてのデバイスを失っても、新しいデバイスでサインインして **「リカバリーキーを使う」** を選べば、フレンドとプロジェクトを引き継げます。紛失したデバイスは残っている別のデバイスから削除してください。盗難に遭った場合は、あわせて新しいリカバリーキーも生成してください。

## 7. フレンドと作業する

アカウント横のメニューから **フレンド** を開きます。自分の招待を送るか、フレンドの招待やユーザー名を貼り付けます。招待を使うと、Kodosi がフレンドの本人確認を自動で行います。モバイルでは招待を QR コードで表示でき、フレンドがカメラまたは Kodosi 内でスキャンできます（リクエスト送信前に信頼の確認ステップが入ります）。

### ターミナルを共有する

ターミナルのヘッダーにあるアクションメニューを開き、**共有** をクリックしてフレンドまたはプロジェクトを選びます。共有相手には、そのコンピュータ上でのあなたの OS 権限と同じフル操作権限が付与されます。ほかのターミナルは非公開のままです。

### プロジェクト

プロジェクトを使うと、どのフォルダやコンピュータにあるターミナルも、共有チャットやタスクリストと一緒にまとめられます。**プロジェクト** の横にある `+` をクリックし、プロジェクト内でターミナルを起動（または既存のターミナルを共有）して、準備ができたらフレンドを招待してください。

<p align="center"><img src="../media/project.webp" width="900" alt="共有ターミナルと、人とエージェントの会話が並ぶプロジェクト画面。"></p>

- メンバー全員が共有ターミナルを使え、自分のターミナルを共有することもできます。後から参加した人も、プロジェクト内のターミナルとこれまでのチャット履歴をすべて見られます。ファイル自体は各ターミナルのホストコンピュータに残ります。
- 担当者のいないタスクを作成し、引き受けたり、手放したり、まとめのメモを添えて完了にしたり、再オープンしたりできます。
- GitHub や Gitea のリポジトリをリンクすると、Issue とタスクを同期できます。リンク済みのタスクを更新すると、元の Issue も更新されます。GitHub は `gh` のログイン情報または Git credential helper を、Gitea は Git credential helper または `KODOSI_GITEA_URL` と組み合わせた `KODOSI_GITEA_TOKEN` を使います。認証情報があなたのコンピュータの外に出ることはありません。
- チャットで `@<terminal-name>` のようにターミナルをメンションすると、あなたの名前とプロジェクト名を添えたメッセージがそのターミナルのエージェントへ直接届き、エージェントがどう応答するかを判断します。Kodosi 内の Claude Code、Copilot CLI、Antigravity CLI（および Kodosi から起動した Codex、Cursor、OpenCode。OpenCode は macOS と Linux のみ）は、Kodosi 内で動いていることを自動で認識します。ほかのエージェントには `kodosi skill` を実行して [skill](../../runtime/skills/kodosi/SKILL.md) を出力してください。Kodosi のターミナル内ではプロジェクトコマンドが現在のプロジェクトを自動検出し、外から実行する場合は `--project <name>` を指定します。
- 自分または自分のエージェントが投稿したメッセージを削除すると、全員の画面で削除済みのプレースホルダーに置き換わります。**チャットを消去** を選ぶと、その時点までの履歴が自分のすべてのデバイスで非表示になりますが、ほかのメンバー側には残ります。

## 8. コマンドラインを使う

`kodosi` CLI はデスクトップアプリとまったく同じターミナルを操作でき、変更は即座にアプリへ反映されます。

| コマンド | 動作 |
| --- | --- |
| `kodosi terminal start --agent claude --prompt "fix the failing test"` | 前回の設定でエージェントを起動します。`--account`、`--model`、`--effort`、`--fast`、`--permissions`、`--output` で上書きできます。 |
| `kodosi terminal start --directory <repository> --branch <name>` | 専用の Git worktree 上の新しいブランチでターミナルを起動します。 |
| `kodosi terminal start --computer <computer> --directory <folder>` | 別の自分のコンピュータでターミナルを起動します。相対パスや `~` はそのコンピュータのホームディレクトリ基準で解決されます。オンラインのコンピュータを確認するには `kodosi devices list` を使います。 |
| `kodosi agent list` | インストール済みのエージェント、アカウント、前回の設定を一覧表示します。 |
| `kodosi agent usage` | サインイン中の Claude Code、Codex、Copilot CLI アカウントの現在のプラン使用量とリセット時刻を表示します。 |
| `kodosi terminal list` | ターミナルを名前と ID 付きで一覧表示します（どちらも `<terminal>` に指定できます）。 |
| `kodosi terminal read <terminal>` | 現在の画面内容を出力します。`--history` を付けるとスクロールバックも含まれます。 |
| `kodosi terminal message <terminal> "Can you review my branch?"` | 送信者と送信元を添えて、ターミナル内のエージェントへメッセージを送信します。 |
| `kodosi terminal agent <terminal> --model sonnet` | 実行中のエージェントのモデル、推論レベル、高速モード、権限を変更します。 |
| `kodosi terminal input <terminal> --enter "make test"` | ターミナルにテキストを入力します。 |
| `kodosi terminal keys <terminal> ctrl-c` | ターミナルにキー入力を送信します。 |
| `kodosi terminal wait <terminal> --until done,failed` | ターミナルが指定した状態のいずれかになるまで待機します。 |
| `kodosi terminal show <terminal>` | アプリ内で指定のターミナルにフォーカスします。 |
| `kodosi dosi say "What needs me?"` | Dosi にメッセージを送ります。`kodosi dosi show` で会話を表示し、`kodosi dosi stop` でターンを中止できます。 |
| `kodosi show <file>` | このターミナルのキャンバスにファイルを開きます。キャンバスは、このターミナルを見ている人の画面で開きます。`kodosi show <address>` で共有ブラウザに URL を開き、`kodosi show browser` で共有ブラウザをそのまま表示、`kodosi canvas` でキャンバス上の項目一覧を表示、`kodosi canvas remove <file>` で項目を削除できます。 |
| `kodosi browser open <address>` | このターミナルの共有ブラウザで URL を開きます（そのほかの agent-browser コマンドもすべて利用できます）。 |
| `kodosi skill` | Kodosi での共同作業用エージェントスキルを出力します。`kodosi skill canvas` でキャンバス用スキルを出力します。 |
| `kodosi dosi skill` | 別のエージェントを Dosi として動かすためのスキルを出力します。 |
| `kodosi host` | ホストプロセスを独立して実行し、アプリ終了後もターミナルを動かし続けます。バックグラウンドホストを止めるには `kodosi host stop` を使います。 |

`message`、`input`、`keys` は、あなたがそのターミナルで入力している最中は実行を拒否します。`message` はエージェントが人間の回答を待っている間も実行しません。

## つながらないときは

- ターミナルのホストコンピュータがオンラインで Kodosi が起動しているか、またターミナルの共有が解除されていないかを確認してください。
- 新しく追加したデバイスが承認待ちのままになっていたり、ID が変わったフレンドについて **フレンド** 画面での再確認が必要になっていたりする場合があります。
- 接続が切れた後は、Kodosi が現在の状態を改めて表示します。リモートターミナルに **オフライン** と表示されているときは、このデバイスからサーバーに接続できていません。ネットワーク接続を確認してください。Kodosi は自動で再接続しますが、**再試行** をクリックすると即座に再接続を試みます。
- ホストコンピュータがオフラインになった場合、その間にターミナルが終了していなければ、コンピュータが戻ると自動で再接続されます。オフラインのターミナルを一覧から外すには `×` をクリックしてください。**オンラインに戻るまで非表示** を選ぶと一時的に隠れ、**完全に閉じる** を選ぶとコンピュータの再接続時に完全に閉じられます。
- 入力が届いたかどうか不確かだという警告が表示された場合は、コマンドを再実行する前にターミナル画面を確認してください。
