# はじめに

[English](../GETTING_STARTED.md) · [Deutsch](../de/GETTING_STARTED.md) · [Ελληνικά](../el/GETTING_STARTED.md) · [Español](../es/GETTING_STARTED.md) · [Français](../fr/GETTING_STARTED.md) · [Italiano](../it/GETTING_STARTED.md) · **日本語** · [한국어](../ko/GETTING_STARTED.md) · [简体中文](../zh-Hans/GETTING_STARTED.md)

お使いのコンピュータ用の [Kodosi を入手](README.md#kodosi-を入手)してください。このガイドでは Mac のキーを使います。Linux と Windows では、同じ文字に Ctrl+Shift を組み合わせます。

## 1. サインイン

Kodosi を開き、サイドバーの下にあるサインインを選びます。Kodosi がブラウザを開くので、そこでサインインします。ターミナルでは、`kodosi auth login` を実行するとコードが表示され、任意のブラウザで入力できます。

アカウントがなくても、Kodosi はこのコンピュータでターミナルを実行できます。ほかのコンピュータ、フレンド、プロジェクトを使うにはサインインしてください。

## 2. エージェントを起動する

新しいターミナル（⌘N）を選びます。エージェントとフォルダを選び、必要ならアカウント、モデル、推論レベルも選びます。最初のプロンプトを入力して Return キーを押すと、Kodosi が新しいターミナルのシェルにコマンドを入力します。

<p align="center"><img src="../media/launcher.webp" width="580" alt="ランチャーで Claude Code を選び、フォルダと最初のプロンプトを入力したところ。"></p>

- 普通のターミナルを開くには ⌘D（Linux と Windows では Ctrl+Shift+O）を押します。選択中のターミナルのフォルダですぐに開きます。⌘T（Ctrl+Shift+T）を押すと、選択中のターミナルのエージェントを同じアカウントと同じ選択で開きます。
- キーは Ghostty に準拠しています。⌘1〜⌘9 でターミナルを選び（Linux と Windows では Alt+1〜Alt+9）、⌥⌘ と矢印キーで隣のターミナルを選び（Ctrl+Alt と矢印キー）、⌘W で選択中のターミナルを閉じます。設定 › ショートカットですべてのキーを確認し、変更できます。
- エージェントが見つからない場合は、ランチャーにインストールコマンドが表示されます。
- エージェントは「制限なし」で起動し、確認せずにファイルを変更したりコマンドを実行したりします。先に確認させたいときは、モデルの次のボタンで「確認」を選びます。Claude Code と Codex が作業をどこまで表示するかもそこで選べます。最初は「簡潔」です。
- 新しいアカウントには、`~/.claude-work` のような専用のサインインフォルダが作られます。`alias cw='CLAUDE_CONFIG_DIR=~/.claude-work claude'` のようにシェルで設定したアカウントも Kodosi が見つけます。
- プロンプトで待機しているターミナルでは、ヘッダーのアクションボタン（2 本のスライダー）にインストール済みのエージェントが並びます。選ぶと前回の設定で起動します。
- エージェントの実行中は、同じアクションボタンで、エージェント自身のコマンドを使ってモデルと推論レベルを変更できます（一部のエージェントでは権限も）。エージェントは再起動しません。変更はエージェントのターンが終わるまで待機し、Claude Code は選んだモデルと推論レベルを次回以降のセッションでも使います。
- zsh と bash（macOS の bash 3.2 を除く）では、⌘↑ と ⌘↓ でプロンプト間を移動できます。
- リンクを開くには ⌘ を押しながらクリックします（Linux と Windows では Ctrl+クリック）。マウスを使うプログラムの中では、さらに Shift も押します。iPhone ではリンクをタップします。マウスを使うプログラムの中では、タップでリンクは開きません。リンクは、使っているデバイスの自分のブラウザで開きます。Kodosi はほかのアプリでリンクを開く前に確認します。プログラムを実行できるファイル、およびほかのコンピュータのターミナルのファイルや `localhost` のアドレスは開きません。
- スクリーンショットなどの画像をエージェントに渡すには、⌘V で貼り付けます（Linux と Windows では Ctrl+Shift+V、iPhone ではペースト）。Kodosi は画像をターミナルのコンピュータに保存してファイルのパスを貼り付け、エージェントがそれを添付します。ほかのコンピュータのターミナルでは、画像がどこまで届いたかが表示されます。Claude Code の Ctrl+V のようなエージェント自身の画像用キーは、エージェントが動いているコンピュータのクリップボードを読み取ります。
- エージェントにリポジトリ専用のコピーを渡すには、サイドバーでリポジトリのフォルダにポインタを合わせ、ブランチボタンを選んでブランチに名前を付けます。Kodosi は新しい Git worktree でターミナルを起動します。ターミナルが終了すると、何も変更がなければ Kodosi が worktree を削除します。これらのフォルダの場所は設定 › ターミナルで決められます。

ターミナルは、それを実行しているコンピュータ上の本物のシェルです。最小化するとターミナルは隠れますが動き続けます。閉じるとターミナルとそのプログラムが終了します。ウインドウを閉じても Kodosi とターミナルは動き続け、Kodosi のアイコンがメニューバーかシステムトレイに残ります。システムトレイのないデスクトップでは、ウインドウを閉じると Kodosi が終了します。Kodosi を終了すると、ターミナルは停止します。Kodosi はターミナルに表示されていた内容をあなたのコンピュータにだけ保存します。Kodosi をもう一度開くと、ターミナルは元のフォルダ、プロジェクト、ステージ上の位置で再び起動し、新しいプロンプトの上に以前の画面と履歴が表示されます（Windows では上にスクロールすると見えます）。Claude Code、Codex、Copilot CLI は会話を続け、Mac と Linux では選んだモデル、推論レベル、権限、出力もそのまま使います。どの会話だったかを Kodosi が判断できないときは、エージェントが会話の一覧を表示するので、続きから再開できます。ウインドウを閉じたときの動作は設定で選べます。

Mac では、ほかのターミナル App と同じく、ターミナルのプログラムには Kodosi に与えたアクセス権があります。macOS が Kodosi による App の変更を阻止したと伝えたときは、ターミナルのプログラムがほかの App を変更しようとしました。許可するには、App管理で Kodosi をオンにします。設定 › 一般 から開けます。デバイスの制御とデータへのアクセス（macOS 27 より前はアクセシビリティ）と画面収録とシステムオーディオ録音も、App を操作したり画面を見たりするプログラムのためにそこで許可します。

## 3. どのエージェントがあなたを必要としているかを見る

各ターミナルのマークは、そのプログラムの状態を表します。

| 表示 | 意味 |
| --- | --- |
| マークのまわりを回る暖かい光 | 作業中。縁が埋まってパーセントを示します。 |
| 手、疑問符、または鍵 | 承認、回答、またはサインインを待っています。 |
| 緑のチェック | 完了。 |
| 黄色の警告マーク | 失敗。 |

チェックと警告はターミナルを開くと消えます。Kodosi がバックグラウンドにあるときは、ターミナルが待機を始めたとき、完了したとき、失敗したときに通知でお知らせします。プログラムは [Program Status Protocol](https://www.superlogical.com/rex/docs/build/program-status) またはプログレスバーで状態を伝えます。何も伝えないプログラムには状態が表示されません。

## 4. エージェントが表示するものを見る

エージェントは、ページ、Markdown、画像、PDF、ドキュメント、シート、プレゼンテーション、実行中のアプリをターミナルのキャンバスに表示したり、あなたと共有するブラウザを使ったりできます。ターミナルを見ているあいだ、エージェントが表示したものでキャンバスが開きます。キャンバス上のファイルやブラウザが変わったときも開きますが、自分で閉じた場合は開きません。自分で開くときだけにするには、設定 › 一般 でキャンバスを自動で開くをオフにします。Claude Code と Copilot CLI は、自分で起動した場合も使い方を知っています。Kodosi が起動した Codex も同様です。ほかのエージェントには `kodosi skill canvas` を読むよう伝えてください。キャンバスに何かがあると、ターミナルのヘッダーにファイル用とブラウザ用のボタンが表示され、新しいものがあると銅色の点が付きます。どちらかを選ぶと、ターミナルの隣にキャンバスが開きます。広く表示を選ぶと、キャンバスがステージを使い、ターミナルは隅に小さく残ります。各部分はボタンの × で閉じ、+ で再び開けます。アクションボタンのブラウザを開くを選ぶと、エージェントが使う前にブラウザを開けます。ファイルを追加… を選ぶと、ファイルがキャンバスとターミナルのフォルダに置かれます。キャンバスにファイルをドロップすることもできます。iPhone では、キャンバスのボタンはターミナルのバーにあり、エージェントが表示したものや変わったものはバナーで知らされ、開くで表示できます。

- ドキュメント、シート、プレゼンテーション、PDF、テキストファイルはライブです。あなた、ターミナルの参加者、エージェントが同時に編集でき、フォルダ内の普通のファイルのままです。ドキュメントに変更履歴があると、バーに変更を承認または却下するボタンが表示されます。設定 › ドキュメントでは、各ビューアのオン／オフ、ドキュメントをページとして表示するかキャンバスに合わせたテキストとして表示するか、Kodosi がダークのときにページも暗くするかを選べます。
- ページはネットワークに接続しません。ページ、ドキュメント、シート、プレゼンテーション、PDF のリンクは、ターミナルのリンクと同じルールで自分のブラウザで開きます。編集できる場所では ⌘ を押しながらリンクをクリックします（Linux と Windows では Ctrl+クリック）。それ以外の場所ではクリックで、iPhone ではタップで開きます。同じファイルのスライドやセルへのリンクは、その場所に移動します。
- ページやドキュメントの言葉を選択し、これについて質問を選びます。Kodosi がファイルとその言葉をターミナルに入力するので、あとは質問を書きます。
- 共有ブラウザでは、自分のブラウザと同じようにクリックや入力ができます。エージェントにも同じページとサインイン状態が見え、次のコマンドであなたがブラウザを使ったことが伝わります。10 分間使われないとブラウザはスリープし、あなたが見るかエージェントが使うと最後のページを再び開きます。コンピュータで最初にブラウザを使うときは Kodosi Browser をダウンロードするため、少し時間がかかります。
- プライベートなターミナルで自分のサインイン情報を使うには、設定 › ブラウザでブラウザの隣にあるコピーを選びます。削除でコピーしたものを取り除き、すべて削除でプライベートなターミナルのサインイン情報とサイトデータをすべて削除します。Mac で、Safari のように macOS がブラウザのサインイン情報を Kodosi から守っている場合は、そのブラウザの隣にある許可…を選んで、Kodosi にフルディスクアクセスを与えます。
- 同じネットワーク内では、ブラウザの映像はデバイス間で直接やり取りされます。macOS と iOS はローカルネットワークへのアクセスを一度だけ求めます。許可しない場合、映像はサービスを経由します。
- ターミナルを開ける人は全員、そのキャンバスを見て、そのブラウザを使えます。ターミナルを閉じると、キャンバスとブラウザのサインイン情報は消えます。

## 5. Dosi に聞く

Dosi は、ほかのエージェントのためのあなたのエージェントです。サイドバーの下にある Dosi の顔を選びます（⌘J）。Dosi は Claude Code か Codex で動きます。どちらを使うかは、アカウント、モデル、推論レベルとあわせて設定 › Dosi で選べます。

何に対応が必要か Dosi に聞くか、何かを頼んでみましょう。Dosi はターミナルとプロジェクトを読んで答え、代わりに入力したり、起動したり、閉じたりします。選択が必要なときはボタンで尋ね、自分の言葉で答えることもできます。Dosi との会話はすべてのデバイスで同じです。iPhone や iPad では、Dosi タブから、メッセージの上で選んだコンピュータの Dosi に書きます。最初は最後に答えたコンピュータが選ばれています。オフラインのコンピュータへのメッセージは、そのコンピュータでもう一度 Kodosi が動くまで待ち、送信しないで取り消せます。

Dosi の顔の隣の行には、Dosi が作業中か、答えたか、質問があるかが表示されます。エージェントがないコンピュータでは Dosi を設定と表示され、設定 › Dosi が開きます。コンピュータから Dosi を外すには、設定 › Dosi で Dosi を使うをオフにします。

## 6. ほかのコンピュータを追加する

新しいコンピュータで同じアカウントにサインインします。コードが表示され、すでに使っているコンピュータに承認を求めるメッセージが届きます。そのうちの 1 台で承認を選び、コードを入力します。iPhone や iPad も同じ方法で追加できます。追加後は、どのコンピュータにもすべてのコンピュータのターミナルが表示されます。

ほかのコンピュータでターミナルを起動するには、ランチャーの帯の右端でそのコンピュータを選びます。フォルダボタンにそのコンピュータの最近のフォルダが並び、フォルダを選択…でホームのフォルダを開けます。iPhone や iPad では、ターミナルの + か、自分のコンピュータの横にある + を選びます。そのコンピュータでは Kodosi が開いているか、ターミナルで `kodosi host` が動いている必要があります。

そこでリカバリーキーも作成し、安全に保管してください。すべてのデバイスをなくした場合は、新しいデバイスでサインインし、「リカバリーキーを使う」を選ぶと、フレンドとプロジェクトをそのまま残せます。なくしたデバイスは別のデバイスから削除します。デバイスが盗まれた場合は、新しいリカバリーキーも作成してください。

## 7. フレンドと作業する

アカウントの隣のメニューからフレンドを開きます。自分の招待を送るか、フレンドの招待やユーザー名を貼り付けます。招待があれば、Kodosi はフレンドを確認できます。

<p align="center"><img src="../media/friends.webp" width="900" alt="確認済みのフレンドが 2 人いるフレンドのページ。"></p>

ターミナルを共有するには、ヘッダーのアクションボタンで共有を選び、フレンドまたはプロジェクトを選びます。共有した相手はフル操作ができ、そのコンピュータでのあなたの権限を持ちます。ほかのターミナルは非公開のままです。

プロジェクトは、どのフォルダやコンピュータのターミナルも、会話やタスクと一緒にまとめます。プロジェクトの隣の + を選び、プロジェクトでターミナルを起動するか、ターミナルをプロジェクトに共有します。フレンドはいつでも招待できます。

<p align="center"><img src="../media/room.webp" width="900" alt="共有ターミナルと、人とエージェントの会話があるプロジェクト。"></p>

- メンバー全員が共有ターミナルを使え、自分のターミナルも共有できます。後から参加した人もターミナルと会話のすべてを受け取ります。ファイルは各ターミナルのコンピュータに残ります。
- タスクを募集し、引き受け、手放し、結果を添えて完了にしたり、再オープンしたりできます。
- GitHub や Gitea のリポジトリをリンクすると、Issue がタスクになります。そのタスクを変更すると、Kodosi が Issue も変更します。GitHub は `gh` のサインインか Git の credential helper を、Gitea は credential helper か、`KODOSI_GITEA_URL` のサーバー用の `KODOSI_GITEA_TOKEN` を使います。認証情報はあなたのコンピュータに残ります。
- チャットに `@` とターミナルの名前を書くと、Kodosi はあなたの名前とプロジェクトを添えて、そのターミナルのエージェントにメッセージを渡します。どうするかはエージェントが決めます。Kodosi のターミナルの Claude Code と Copilot CLI、そして Kodosi が起動した Codex は、Kodosi の中で動いていることを知っています。`kodosi skill` は、エージェントが参加するための [skill](../../runtime/skills/kodosi/SKILL.md) を出力します。Kodosi のターミナルではコマンドがプロジェクトを見つけます。それ以外の場所では `--project <name>` を追加してください。

## 8. コマンドラインを使う

`kodosi` コマンドはアプリと同じターミナルを操作し、その動作はアプリに表示されます。

| コマンド | 動作 |
| --- | --- |
| `kodosi terminal start --agent claude --prompt "fix the failing test"` | 前回の設定でエージェントを起動します。`--account`、`--model`、`--effort`、`--permissions`、`--output` で変更できます。 |
| `kodosi terminal start --directory <repository> --branch <name>` | 専用の worktree の新しいブランチでターミナルを起動します。 |
| `kodosi terminal start --computer <computer> --directory <folder>` | ほかのコンピュータでターミナルを起動します。相対パスのフォルダや `~` で始まるフォルダは、そのコンピュータのホームにあるものです。どのコンピュータがオンラインかは `kodosi devices list` で確認できます。 |
| `kodosi agent list` | エージェント、そのアカウント、前回の設定を表示します。 |
| `kodosi agent usage` | サインイン中の Claude Code、Codex、Copilot CLI の各アカウントが、プランの上限をどれだけ使ったかを表示します。 |
| `kodosi terminal list` | ターミナルを名前と ID 付きで表示します。どちらも `<terminal>` に指定できます。 |
| `kodosi terminal read <terminal>` | 画面を出力します。`--history` を付けると、スクロールで流れた行も加わります。 |
| `kodosi terminal message <terminal> "Can you review my branch?"` | 送信者と送信元を添えて、ターミナルのエージェントにメッセージを渡します。 |
| `kodosi terminal agent <terminal> --model sonnet` | 実行中のターミナルのエージェントのモデル、推論レベル、権限を変更します。 |
| `kodosi terminal input <terminal> --enter "make test"` | 1 行入力します。 |
| `kodosi terminal keys <terminal> ctrl-c` | キーを押します。 |
| `kodosi terminal wait <terminal> --until done,failed` | 指定した状態になるまで待ちます。 |
| `kodosi terminal show <terminal>` | アプリでターミナルを表示します。 |
| `kodosi dosi say "What needs me?"` | Dosi に聞きます。`kodosi dosi show` は会話を出力し、`kodosi dosi stop` は Dosi を止めます。 |
| `kodosi show <file>` | このターミナルのキャンバスにファイルを表示し、ターミナルを見ている人のキャンバスを開きます。`kodosi show <address>` はウェブアドレスをブラウザに表示します。`kodosi canvas` は表示中のものを一覧し、`kodosi canvas remove <file>` はファイルを取り除きます。 |
| `kodosi browser open <address>` | このターミナルの共有ブラウザでページを開きます。agent-browser のほかのコマンドも使えます。 |
| `kodosi skill` | Kodosi の人やエージェントと作業するための skill を出力します。`kodosi skill canvas` はキャンバス用の skill を出力します。 |
| `kodosi dosi skill` | ほかのエージェントが Dosi として動くための skill を出力します。 |
| `kodosi host` | アプリを終了した後もターミナルを動かし続けます。`kodosi host stop` はバックグラウンドで動くホストを止めます。 |

`message`、`input`、`keys` は、あなたがそのターミナルで入力している間はメッセージを表示して止まります。`message` は、エージェントが人の回答を待っている間も止まります。

## つながらないときは

ターミナルのコンピュータがオンラインで Kodosi が開いているか、ターミナルがまだ共有されているかを確認してください。新しいデバイスは承認が必要な場合があり、ID が変わったフレンドはフレンドで確認が必要な場合があります。接続が切れた後は、Kodosi が現在の状態を再び表示します。別のコンピュータのターミナルに「オフライン」と表示された場合は、このデバイスがサーバーにつながっていません。ネットワークを確認してください。Kodosi は自動的に接続し直し、「再試行」を選ぶとすぐに接続します。Kodosi がコンピュータはオフラインだと表示した場合、そのターミナルは、向こうで終了していなければ、コンピュータが戻ったときに再び開きます。そのようなターミナルを一覧から外すには、その X を選びます。「オンラインに戻るまで非表示」を選ぶとコンピュータが戻ったときに再び表示され、「完全に閉じる」を選ぶとそのときに閉じます。入力が届いたか確かでないと Kodosi が表示した場合は、コマンドを入力し直す前にターミナルを確認してください。
