# 安全

[English](../SECURITY.md) · [Deutsch](../de/SECURITY.md) · [Ελληνικά](../el/SECURITY.md) · [Español](../es/SECURITY.md) · [Français](../fr/SECURITY.md) · [Italiano](../it/SECURITY.md) · [日本語](../ja/SECURITY.md) · [한국어](../ko/SECURITY.md) · **简体中文**

你的设备会对终端流量和房间内容进行端到端加密。私钥只留在设备上。后端负责转发连接并存储加密后的房间数据；它从不执行命令，也看不到命令的明文。[加密设计](../CRYPTOGRAPHY.md)（英文）介绍了威胁模型、机制和已知限制；目前还没有独立第三方对其进行审计。

## 共享会授予什么

共享终端即授予完全控制权，权限等同于主机用户在操作系统中的权限。放在房间里的终端会共享给其所有者在该房间中的好友，包括之后加入的好友。移除好友后，对方将失去你的终端，你们也会各自退出对方拥有的房间。共享终端以你的身份运行：其中的人也可以以你的身份运行 `kodosi`，并读取和修改你在那台电脑上的文件，所以只与你放心把那台电脑交给的人共享。Kodosi 信任所有共享终端或房间的人，以及他们终端中的程序和 Agent，不会限制他们的行为。你的每台已批准设备都可以控制你所有的终端，并可以在你其他运行 Kodosi 的电脑上启动新终端。

所有能打开某个终端的人也能看到它画布上的文件，并使用它的共享浏览器，所以只在所有人都可以操作的地方登录。共享终端的共享浏览器永远不会使用你保存的登录信息。画布上的文件是普通文件，所有能打开该终端的人都可以编辑它们。画布上的页面和实时文档运行在一个封闭的框架中，没有网络、没有文件，也没有会保留下来的存储。共享浏览器处于唤醒状态时，它的调试端口和每个窗口的驱动端口都在 `127.0.0.1` 上监听，这台电脑上的其他账户可以访问它们。共享浏览器中的网站每次由人或 Agent 执行一个操作，就会向终端的文件夹保存一个下载文件；只有在你复制时，它才能访问你的剪贴板。当某台设备打开另一台电脑上终端的浏览器时，那台电脑会在一个 TCP 端口上监听几秒钟，以便两者直接连接。只有那台设备能够连入，并使用终端的加密。Linux 应用只在 Chromium 能将页面放入沙盒的情况下显示页面；在 Ubuntu 上，应用的 AppArmor 配置允许应用、其页面进程和 Kodosi Browser 创建沙盒所需的用户命名空间。出于同样的原因，共享浏览器在 Linux 上不会以 root 身份运行。应用本身不包含 Kodosi Browser。当一台电脑打开它的第一个共享浏览器时，它的主机会从 `updates.kodosi.com` 上的更新源获取浏览器，并每天在那里检查新版本。只有当更新源带有 Kodosi 更新密钥的签名，且下载文件的 SHA-256 与更新源给出的一致时，主机才会使用该下载。

## 服务能看到什么

服务能看到账号和设备记录、房间成员、房间和终端的元数据、每个终端的 Agent 和状态（例如工作中或等待批准，但从不包括其文本）、路由字段、时间信息和密文大小。加密不会隐藏这些元数据，也无法防止服务中断。你移除的设备从那一刻起会失去访问权限。移除丢失或被盗的设备后，请生成新的恢复密钥，把那台设备挡在外面。当你有设备时，如果有人在你的账号上重新开始，会先等待一天，并在你的设备上显示，让你可以阻止。GitHub 和 Gitea 的凭据留在你的电脑上。

删除账号会移除其设备、恢复数据、好友、共享和其拥有的房间；在他人房间中发送的消息会保留，但不再关联账号。在 30 天内，服务会保留已删除登录的签发者和主体，以拒绝更早的令牌。

## 校验下载的文件

每个发布版本都附有 `SHA256SUMS`（列出其中每个文件的 SHA-256）和 `SHA256SUMS.asc`（这份列表的签名）。签名所用的 Kodosi 密钥也会为 apt 仓库签名。把这两个文件放在下载的文件旁边，然后运行：

```sh
curl -fsSLO https://updates.kodosi.com/apt/kodosi-archive-keyring.pgp
gpgv --keyring ./kodosi-archive-keyring.pgp SHA256SUMS.asc SHA256SUMS
shasum -a 256 --ignore-missing -c SHA256SUMS
```

GnuPG 的 `gpgv` 必须报告密钥 `E8007A36D199B6EE755B1EE9C612C00442E52299` 的有效签名，`shasum` 必须对你下载的文件显示 OK。

## 报告漏洞

请使用[私密漏洞报告](https://github.com/johnkozaris/Kodosi/security/advisories/new)，或发送邮件至 [security@kodosi.com](mailto:security@kodosi.com)，附上修订版本、复现步骤、影响以及隐去敏感信息的日志。请勿在公开 Issue 中透露细节。
