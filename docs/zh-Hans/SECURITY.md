# 安全

[English](../SECURITY.md) · [Deutsch](../de/SECURITY.md) · [Ελληνικά](../el/SECURITY.md) · [Español](../es/SECURITY.md) · [Français](../fr/SECURITY.md) · [Italiano](../it/SECURITY.md) · [日本語](../ja/SECURITY.md) · [한국어](../ko/SECURITY.md) · **简体中文**

你的设备会对终端流量和房间内容进行端到端加密。私钥只留在设备上。后端负责转发连接并存储加密后的房间数据；它从不执行命令，也看不到命令的明文。[加密设计](../CRYPTOGRAPHY.md)（英文）介绍了威胁模型、机制和已知限制；目前还没有独立第三方对其进行审计。

## 共享会授予什么

共享终端即授予完全控制权，权限等同于主机用户在操作系统中的权限。房间里的每个人都可以使用房间的共享终端，包括之后受邀加入的成员。共享一个终端不会共享其他任何东西。Kodosi 信任所有共享终端或房间的人，以及他们终端中的程序和 Agent，不会限制他们的行为。你的每台已批准设备都可以控制你所有的终端，并可以在你其他运行 Kodosi 的电脑上启动新终端。

所有能打开某个终端的人也能看到它画布上的文件，并使用它的共享浏览器，所以只在所有人都可以操作的地方登录。共享终端永远不会带有你保存的登录信息。画布上的文件是普通文件，所有能打开该终端的人都可以编辑它们。画布上的页面和实时文档运行在一个封闭的框架中，没有网络、没有文件，也没有会保留下来的存储。共享浏览器处于唤醒状态时，它的调试端口在 `127.0.0.1` 上监听，这台电脑上的其他账户可以访问它。当某台设备打开另一台电脑上终端的浏览器时，那台电脑会在一个 TCP 端口上监听几秒钟，以便两者直接连接。只有那台设备能够连入，并使用终端的加密。Linux 应用只在 Chromium 能将页面放入沙盒的情况下显示页面；在 Ubuntu 上，应用的 AppArmor 配置允许应用及其页面进程创建沙盒所需的用户命名空间。

## 服务能看到什么

服务能看到账号和设备记录、房间成员、房间和终端的元数据、每个终端的 Agent 和状态（例如工作中或等待批准，但从不包括其文本）、路由字段、时间信息和密文大小。加密不会隐藏这些元数据，也无法防止服务中断。你移除的设备从那一刻起会失去访问权限。移除丢失或被盗的设备后，请生成新的恢复密钥，把那台设备挡在外面。GitHub 和 Gitea 的凭据留在你的电脑上。

删除账号会移除其设备、恢复数据、好友、共享和其拥有的房间；在他人房间中发送的消息会保留，但不再关联账号。在 30 天内，服务会保留已删除登录的签发者和主体，以拒绝更早的令牌。

## 报告漏洞

请使用[私密漏洞报告](https://github.com/johnkozaris/Kodosi/security/advisories/new)，或发送邮件至 [security@kodosi.com](mailto:security@kodosi.com)，附上修订版本、复现步骤、影响以及隐去敏感信息的日志。请勿在公开 Issue 中透露细节。
