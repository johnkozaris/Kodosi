# 快速上手

[English](../GETTING_STARTED.md) · [Deutsch](../de/GETTING_STARTED.md) · [Ελληνικά](../el/GETTING_STARTED.md) · [Español](../es/GETTING_STARTED.md) · [Français](../fr/GETTING_STARTED.md) · [Italiano](../it/GETTING_STARTED.md) · [日本語](../ja/GETTING_STARTED.md) · [한국어](../ko/GETTING_STARTED.md) · **简体中文**

为你的电脑[下载 Kodosi](README.md#获取-kodosi)。下文的快捷键均以 macOS 为准；在 Linux 和 Windows 上，除非另有说明，请将 ⌘ 替换为 Ctrl+Shift。

## 1. 登录

打开 Kodosi，点击侧边栏底部的 **登录**，Kodosi 会在浏览器中打开登录页面。你也可以在终端里运行 `kodosi auth login` 获取设备代码，并在任意浏览器中输入该代码完成登录。

无需登录即可在本地运行终端。登录后，你可以连接自己的其他电脑、添加好友以及使用项目功能。

## 2. 启动 Agent

按 ⌘N（或点击 **新建终端**）打开启动器。选择一个 Agent 和目标文件夹，按需指定账号、模型和推理强度，输入初始提示词后按 Return 键，Kodosi 就会在新的 shell 中自动输入启动命令。

<p align="center"><img src="../media/launcher.webp" width="580" alt="启动器已配置 Claude Code、目标文件夹和初始提示词。"></p>

如果某个 Agent 尚未安装，启动器会直接显示它的安装命令。

### 快速打开终端

- 按 ⌘D（Linux 和 Windows 上为 Ctrl+Shift+O），在当前所选终端所在的文件夹中打开一个普通 shell。
- 按 ⌘T（Linux 和 Windows 上为 Ctrl+Shift+T），沿用当前所选终端的 Agent、账号和设置打开一个新终端。
- 点击侧边栏中文件夹旁的 `+` 按钮，使用该文件夹中正在运行的 Agent，以相同的账号和设置再启动一个终端（如果该文件夹没有运行中的 Agent，则打开普通 shell）。
- 在停留在 shell 提示符处的空闲终端中，点击标题栏里的操作按钮（双滑块图标），即可按上次使用的设置启动任意已安装的 Agent。

### 键盘快捷键

快捷键与 Ghostty 默认设置保持一致，你可以在 **设置 › 快捷键** 中自定义：

- ⌘1 到 ⌘9（Linux 和 Windows 上为 Alt+1 到 Alt+9）：按位置切换终端。
- ⌥⌘ 加方向键（Linux 和 Windows 上为 Ctrl+Alt 加方向键）：切换到相邻的终端。
- ⌘W：关闭当前所选终端。
- ⌘↑ 和 ⌘↓：在 zsh 和较新版本的 bash 中按 shell 提示符上下跳转（不支持 macOS 自带的 bash 3.2）。

### 权限、详细程度与快速模式

- Agent 默认以不受限制的模式启动，可以直接编辑文件和运行命令而无需逐次确认。Antigravity CLI 是唯一的例外：它会以自身的自动模式启动，在执行不可逆操作前仍会询问你。若希望 Agent 在操作前先请求许可，请在模型选择器后面的 **更多** 中选择 **询问**。
- 在 **更多** 中，你还可以为 Claude Code、Codex、Copilot CLI 和 Antigravity CLI 设置输出详细程度（默认为 **简洁**）。由于 Copilot CLI 只会从已保存的配置文件中读取详细程度，在 Copilot CLI 以简洁模式运行期间，Kodosi 会临时修改其配置，并在结束后恢复原状。
- Claude Code 和 Codex 支持快速模式（响应更快，但费用更高），你可以在模型和推理强度选择器旁边切换。快速模式仅对当次启动生效，下次启动时会自动重置为关闭状态。

### 账号与运行中切换

- 添加新账号时，Kodosi 会为它分配独立的配置文件夹（例如 `~/.claude-work`）。Kodosi 也能自动识别通过 shell 别名定义的账号，例如 `alias cw='CLAUDE_CONFIG_DIR=~/.claude-work claude'`。
- 在 Agent 运行期间，你可以点击标题栏的操作按钮（双滑块图标）随时切换它的模型、推理强度、快速模式，以及权限（适用于支持的 Agent），无需重启。Kodosi 会在当前轮次结束后发送该 Agent 对应的斜杠命令。请注意，Claude Code 还会记住你更改的模型、推理强度和快速模式，并在后续会话中沿用。

### 链接、图片、Worktree 与主题

按住 ⌘ 点击链接（Linux 和 Windows 上按住 Ctrl 点击）即可在你当前所用设备的默认浏览器中打开；如果当前运行的程序接管了鼠标，请同时按住 Shift。在 iPhone 上轻点链接即可打开（当程序接管鼠标时不可用）。将链接交给其他应用打开前，Kodosi 会先向你确认；同时，Kodosi 会阻止打开可执行文件，也不会打开来自远程电脑的本地文件路径或 `localhost` 地址。

要向 Agent 发送截图或图片，直接按 ⌘V 粘贴即可（Linux 和 Windows 上按 Ctrl+Shift+V，iPhone 上点击“粘贴”）。Kodosi 会将图片保存到终端所在的宿主机上，并粘贴其文件路径供 Agent 附加使用；对于远程终端，还会显示上传进度。Agent 自身的粘贴快捷键（如 Claude Code 中的 Ctrl+V）仍读取运行该 Agent 的那台电脑的剪贴板。

若想为 Agent 提供独立的 Git 仓库副本，可在侧边栏将鼠标悬停在仓库文件夹上，点击分支按钮并输入分支名。Kodosi 会在新的 Git worktree 中打开终端；终端关闭时如果未产生任何改动，该 worktree 会被自动清理。你可以在 **设置 › 终端** 中配置 worktree 的存放位置。

无论在什么设备上查看，每个终端的浅色或深色外观都与其宿主机上的 Kodosi 保持一致。终端内的程序会收到主题变化通知，因此像 Claude Code（将 `/theme` 设为 Auto 时）这类工具也能自动适配。如果你希望在 Kodosi 使用浅色模式时依然保持深色终端，请在 **设置 › 终端** 中开启 **终端始终保持深色**。

### 关闭、退出与 macOS 权限

每个终端都是运行在宿主机上的真实 shell。**最小化** 只会隐藏终端，不会中止运行；**关闭** 则会结束该 shell 及其所有子进程。关闭应用窗口后，Kodosi 和你的终端会继续在菜单栏或系统托盘中运行（在没有系统托盘的 Linux 桌面环境中，关闭窗口会直接退出 Kodosi）。你可以在 **设置** 中更改关闭窗口时的行为。

退出 Kodosi 时，你的终端会停止运行，Kodosi 会将它们的屏幕状态保存在本地电脑上（绝不上传到服务器）。下次打开 Kodosi 时，各个终端会在原来的文件夹、项目和舞台位置重新启动，并在新提示符上方保留先前的屏幕内容与回滚记录（在 Windows 上向上滚动即可查看）。Claude Code、Codex 和 Copilot CLI 会自动恢复各自的对话；在 macOS 和 Linux 上，它们还会保留你选择的模型、推理强度、快速模式、权限和详细程度。如果 Kodosi 无法识别 Agent 之前所在的对话，该 Agent 会列出对话列表供你选择。

在 macOS 上，和其他终端应用一样，运行在 Kodosi 内的程序会继承你授予 Kodosi 的系统权限。如果 macOS 阻止某个程序修改其他应用，请在 **App 管理** 中启用 Kodosi（可通过 **设置 › 常规** 快速打开）。如果终端内的工具需要自动控制其他应用或截取屏幕，也可以在同一位置授予 **设备控制和数据访问**（macOS 27 之前称为 **辅助功能**）和 **录屏与系统录音** 权限。

## 3. 看看哪个 Agent 需要你

每个终端的图标都会反映它当前的状态：

| 图标状态 | 含义 |
| --- | --- |
| 绕图标旋转的暖色光环 | 正在工作（程序上报进度时，光环会随百分比逐步填满）。 |
| 手势、问号或钥匙 | 正在等待你的批准、回答或登录。 |
| 绿色对勾 | 已完成。 |
| 黄色警告三角 | 已失败。 |

在任意设备上打开该终端后，对勾和警告图标就会消失。

当某个终端进入等待、完成或失败状态时，Kodosi 只会在你当前实际使用的设备上提醒你一次：

- 如果 Kodosi 正处于前台焦点，你只会看到状态图标变化。
- 如果你正在电脑上使用其他应用，Kodosi 会在那台电脑上弹出桌面通知。
- 如果你离开了所有电脑，Kodosi 会向你的手机发送推送通知。如果你离开电脑时还有等待中的终端尚未查看，通知也会在此时转发到手机上。

只有处于等待状态的终端才会播放提示音。你可以在 **设置** 中按设备单独关闭通知。程序通过 [Program Status Protocol](https://www.superlogical.com/rex/docs/build/program-status) 或标准终端进度序列上报状态；不上报状态的程序则不显示任何状态图标。

### 聊天视图

运行 Claude Code 的终端，以及通过 Kodosi 启动的 Codex 和 Copilot CLI 终端，还在标题栏提供了 **聊天** 视图。聊天视图会展示你的消息、Agent 的回复和工具调用记录，并以可点击的按钮呈现待回答的问题。你可以直接在聊天视图中回复或中止 Agent；在它提问时输入自定义内容，就能直接指示它改做什么。你在聊天视图中进行的所有操作，都会同步发生在底层终端中。

## 4. 在画布上查看 Agent 展示的内容

Agent 可以在终端旁的 **画布** 上展示 HTML 页面、Markdown、图片、PDF、Office 文档、电子表格、演示文稿或运行中的网页应用，还可以操作共享浏览器。默认情况下，当你正在查看该终端时，只要 Agent 展示或更新了内容，画布就会自动打开（除非你已手动将其关闭）。若只想自己打开画布，请在 **设置 › 常规** 中关闭 **自动打开画布**。

Claude Code、Copilot CLI 和 Antigravity CLI 即使由你手动启动也了解如何使用画布；Codex、Cursor 和 OpenCode 则在通过 Kodosi 启动时知道如何使用（OpenCode 限 macOS 和 Linux）。对于其他 Agent，让它运行 `kodosi skill canvas` 即可。

画布上有内容后，终端标题栏会出现 **文件** 和 **浏览器** 按钮，有新内容时还会显示铜色圆点：

- 点击任意一个按钮，即可在终端旁展开画布。
- 点击 **更多空间**，让画布占据整个舞台，同时将终端缩小至角落。
- 点击按钮上的 `×` 可关闭对应面板，点击 `+` 可重新打开。
- 你可以在操作菜单中点击 **打开浏览器** 手动启动共享浏览器，也可以点击 **添加文件…**（或直接拖放文件到画布上）添加文件，添加的文件会同时复制到该终端的文件夹中。
- 在 iPhone 上，画布按钮位于终端栏中；有新增或更新的内容时，界面会显示提示横幅和 **打开** 按钮。

### 实时文档与页面

- 文档（`.docx`）、电子表格（`.xlsx`）、演示文稿（`.pptx`）、PDF 和文本文件均为实时文档：你、共享该终端的成员以及 Agent 可以同时编辑，它们在磁盘上依然是普通文件。当文档包含修订记录时，工具栏中会提供接受或拒绝修订的控件。在 **设置 › 文档** 中，你可以单独开关各类查看器、在分页视图与自适应流式文本视图之间切换，以及开启深色模式下的暗色页面显示。
- 画布上的 HTML 页面完全离线运行，无法访问网络。页面、文档、表格、幻灯片和 PDF 中的链接都会按照与终端链接相同的安全规则，在你自己的浏览器中打开（在可编辑视图中按住 ⌘ 点击或按住 Ctrl 点击，其他区域直接点击，iPhone 上轻点即可）。指向同一文件内某张幻灯片或某个单元格的内部链接则会直接跳转过去。
- 在页面或文档中选中一段文字后点击 **就此提问**，Kodosi 会直接将文件名和所选内容发送到终端中，方便你接着输入问题。
- 右键点击文件标签页（手机上长按），可以保存副本、从画布中移除该文件或全部文件，或将文件移至宿主机的回收站。

### 共享浏览器

- 在共享浏览器中，你可以像使用普通浏览器一样点击和输入。Agent 看到的页面和登录状态与你完全一致；Agent 执行下一条浏览器命令时，命令输出会告诉它你使用过浏览器。
- 闲置 10 分钟后，共享浏览器会自动休眠；当你或 Agent 再次使用时，它会重新打开上次浏览的页面。在一台电脑上首次打开共享浏览器时，Kodosi 会自动下载 Kodosi Browser，因此需要稍等片刻。
- 若想在私有终端中复用你现有浏览器的登录状态，请在 **设置 › 浏览器** 中点击对应浏览器旁的 **复制**。点击 **移除** 可清除已复制的内容，点击 **全部移除** 则会清除所有私有终端中的登录信息与网站数据。在 macOS 上，如果系统限制访问某个浏览器的数据（例如 Safari），请点击该浏览器旁的 **允许…** 以授予“完全磁盘访问权限”。
- 凡是有权访问该终端的人，都能查看它的画布并使用其共享浏览器。终端关闭后，画布内容会被清空，共享终端浏览器中的登录状态也会被丢弃。

你可以直接问 Dosi 有哪些事需要你处理，或者让它帮你代办某项操作。它能检查你的终端和项目、回复提示、启动或关闭终端以及转达消息。当需要你做决定时，Dosi 会提供选项按钮，同时附带输入框方便你用自己的话回复。

你与 Dosi 的对话会在你的所有设备间保持同步。在 iPhone 和 iPad 上，你可以在输入框上方选择要给哪台电脑上的 Dosi 发消息（默认选中最后回复的那台）。发往离线电脑的消息会先排队，待该电脑重新上线后自动发送；你也可以点击 **不发送** 取消排队中的消息。

Dosi 头像旁的状态栏会提示它是在工作中、已回复还是在等待你的回答。如果该电脑尚未安装任何可用的 Agent，此处会显示 **设置 Dosi**，点击即可打开 **设置 › Dosi**。若要在某台电脑上停用 Dosi，请在 **设置 › Dosi** 中关闭 **使用 Dosi**。

## 6. 添加其他电脑和手机

在新电脑上使用同一个账号登录。新电脑会显示一个验证码，你现有的设备也会收到批准提示。在一台已批准的电脑上点击 **批准** 并输入验证码，或者用已批准手机上的 Kodosi 扫码即可完成验证。

添加手机或平板只需扫码一次：在已批准的电脑上打开 **设置**，在 **添加设备** 下点击 **显示二维码**，然后用新设备扫描。批准后，你所有电脑上的终端都会在各个设备上同步显示。

### 远程启动终端

要在另一台电脑上启动终端，只需在启动器栏右侧选择那台电脑。随后的文件夹菜单会列出那台机器最近使用的文件夹，点击 **选择文件夹…** 则可以浏览其主目录。在 iPhone 和 iPad 上，轻点 **终端** 中或指定电脑旁的 `+` 即可。目标电脑需要保持 Kodosi 处于打开状态（或在终端中运行 `kodosi host`）。

当你的两台设备可以互相直接连通时，终端和浏览器流量会点对点直连传输，以获得更低的延迟。在局域网环境中，macOS、iOS 和 Android 会请求一次本地网络权限；如果拒绝，流量将回退至中继服务器转发。

### 睡眠与保持唤醒

当 Agent 在某台电脑的终端中工作时，这台电脑不会自行进入睡眠；Agent 停止几分钟后，它可以再次进入睡眠。等待你回复的 Agent 不会让它保持唤醒。如需更改，请在该电脑的 **设置 › 常规** 中为 **保持唤醒** 选择 **Agent 工作时**、**始终** 或 **永不**。**始终** 只在电脑接通电源时让它保持唤醒；使用电池时，它只在 Agent 工作时保持唤醒。你随时可以自己让电脑进入睡眠。

要让你的另一台电脑进入睡眠，请打开 **设置**，在 **你的设备** 下点击它旁边的 **⋯**，然后选择 **睡眠…**。在手机上，请点按这台电脑以打开它的页面。在它被唤醒之前，它的终端会暂停。如果之后没有办法唤醒它，Kodosi 会先告诉你。在同一菜单或页面中，你可以选择那台电脑何时保持唤醒。

### 唤醒电脑

要唤醒一台睡眠中的电脑，请在 **设置** 中它的旁边（在手机上是它的页面）、它的某个终端上，或新建终端的电脑列表中点击 **唤醒**。唤醒信号必须从睡眠电脑所在的网络内部发出。如果你正在使用的设备在同一网络中，Kodosi 会从这台设备发送信号；否则会从该网络中你的另一台处于唤醒状态的电脑发送。iPhone 和 iPad 始终会请你的一台电脑代为发送。

电脑只能通过网线唤醒，不能通过 Wi-Fi 唤醒，并且需要系统允许。**设置** 会为每台电脑显示 Kodosi 的预期，或需要更改的那一项设置：

- 在 Mac 上，请在“系统设置”中打开 **唤醒以供网络访问**。
- 在 Windows 上，请在“设备管理器”中允许网络适配器唤醒电脑。
- 在 Linux 上，请为有线连接打开 Wake-on-LAN。

只有在允许 Kodosi 使用本地网络时，Mac 才会发送唤醒信号。请在“系统设置”的 **隐私与安全性** 中允许。

要确认是否有效，请在一台处于唤醒状态的电脑的菜单中选择 **测试唤醒…**（在手机上是在它的页面中）。Kodosi 会让它进入睡眠，再唤醒它，并保存结果。第一次测试时请留在电脑附近：如果它没有被唤醒，请手动唤醒它。

### 恢复密钥

请在 **设置** 中创建一个恢复密钥并妥善保管。即使不慎丢失所有设备，只要在新设备上登录并选择 **使用我的恢复密钥**，就能找回你的好友和项目。如有设备遗失，请尽快在其余设备上将其移除；如果设备被盗，移除后还应重新生成一个新的恢复密钥。

## 7. 与好友协作

从账号旁的菜单中打开 **好友**。你可以发送自己的邀请，或粘贴好友发来的邀请或用户名。通过邀请添加时，Kodosi 会自动验证好友身份。在手机上，你还可以把邀请展示为二维码，让好友用系统相机或在 Kodosi 内扫码；在好友请求发出前，对方仍需确认信任你的身份。

<p align="center"><img src="../media/friends.webp" width="900" alt="“好友”页面，显示两位已验证的好友。"></p>

### 共享终端

打开终端标题栏的操作菜单，点击 **共享**，然后选择要共享的好友或项目。获得共享的成员将拥有该终端的完全控制权，且具备你在那台电脑上的操作系统权限。你的其他终端依然保持私有。只要运行该终端的电脑在线，你就可以在任意一台设备（包括手机）上共享。每当有新的人获得访问权限时，Kodosi 都会请你确认。

### 项目

项目可以将来自任意文件夹或电脑的终端与共享聊天室、任务列表整合在一起。点击 **项目** 旁的 `+`，随后在项目内启动终端（或将已有终端共享到项目中），准备好后即可邀请好友加入。

<p align="center"><img src="../media/project.webp" width="900" alt="一个包含共享终端以及人与 Agent 对话的项目。"></p>

- 每位成员都可以使用共享终端，也可以共享自己的终端。后加入的成员会立即看到项目中的终端以及完整的聊天记录。所有文件依然保存在各自终端所在的宿主机上。
- 你可以创建待认领的任务，进行认领、释放，附带总结说明关闭任务，或重新打开任务。
- 关联 GitHub 或 Gitea 仓库可将 Issue 与任务双向同步：更新关联任务会同步更新对应的 Issue。GitHub 使用你本机的 `gh` 登录状态或 Git 凭据助手；Gitea 使用 Git 凭据助手，或配合 `KODOSI_GITEA_URL` 使用 `KODOSI_GITEA_TOKEN`。你的凭据绝不会离开本机。
- 在聊天中使用 `@<terminal-name>` 提及某个终端，消息就会连同你的名称和所属项目直接送达该终端中运行的 Agent，并由 Agent 决定如何回应。在 Kodosi 内运行的 Claude Code、Copilot CLI 和 Antigravity CLI，以及通过 Kodosi 启动的 Codex、Cursor 和 OpenCode（OpenCode 限 macOS 和 Linux），都会自动感知自己身处 Kodosi 之中。对于其他 Agent，可运行 `kodosi skill` 输出对应的协作 [skill](../../runtime/skills/kodosi/SKILL.md)。在 Kodosi 终端内执行项目命令时会自动识别当前项目；在外部终端中则需传入 `--project <name>`。
- 删除你或你的 Agent 发送的消息后，所有成员都会在该位置看到一条已删除的占位提示。**清空聊天** 会在你的所有设备上隐藏截至当前的历史记录，但不会影响其他成员的聊天记录。

## 8. 使用命令行

`kodosi` 命令行工具与桌面应用控制的是同一批终端，所有变更都会立即同步显示在应用中。

| 命令 | 作用 |
| --- | --- |
| `kodosi terminal start --agent claude --prompt "fix the failing test"` | 按上次使用的设置启动 Agent。可通过 `--account`、`--model`、`--effort`、`--fast`、`--permissions` 和 `--output` 覆盖默认选项。 |
| `kodosi terminal start --directory <repository> --branch <name>` | 在新的分支和独立的 Git worktree 中启动终端。 |
| `kodosi terminal start --computer <computer> --directory <folder>` | 在你的另一台电脑上启动终端。相对路径和 `~` 会按那台电脑上你的主目录解析。使用 `kodosi devices list` 可查看哪些电脑在线。 |
| `kodosi agent list` | 列出已安装的 Agent、它们的账号以及你上次使用的设置。 |
| `kodosi agent usage` | 显示已登录的 Claude Code、Codex 和 Copilot CLI 账号当前的套餐用量与重置时间。 |
| `kodosi terminal list` | 列出所有终端及其名称和 ID（两者均可作为 `<terminal>` 参数使用）。 |
| `kodosi terminal read <terminal>` | 输出终端当前的屏幕内容。加上 `--history` 可包含回滚历史记录。 |
| `kodosi terminal message <terminal> "Can you review my branch?"` | 向指定终端内的 Agent 发送一条附带发送者和来源标记的消息。 |
| `kodosi terminal agent <terminal> --model sonnet` | 在线更改运行中 Agent 的模型、推理强度、快速模式或权限。 |
| `kodosi terminal input <terminal> --enter "make test"` | 向终端输入文本。 |
| `kodosi terminal keys <terminal> ctrl-c` | 向终端发送按键事件。 |
| `kodosi terminal wait <terminal> --until done,failed` | 阻塞等待，直到终端进入指定的任意状态。 |
| `kodosi terminal show <terminal>` | 在应用中聚焦并显示该终端。 |
| `kodosi dosi say "What needs me?"` | 向 Dosi 发送消息。使用 `kodosi dosi show` 可输出对话内容，`kodosi dosi stop` 可取消当前轮次。 |
| `kodosi show <file>` | 在当前终端的画布上打开文件，画布会为正在查看该终端的人打开。使用 `kodosi show <address>` 可在共享浏览器中打开网址，`kodosi show browser` 按当前状态唤出浏览器，`kodosi canvas` 列出画布内容，`kodosi canvas remove <file>` 移除指定文件。 |
| `kodosi browser open <address>` | 在当前终端的共享浏览器中打开网址（同样支持其他所有 agent-browser 命令）。 |
| `kodosi skill` | 输出供 Agent 在 Kodosi 中协作使用的 skill；`kodosi skill canvas` 输出画布相关的 skill。 |
| `kodosi dosi skill` | 输出让其他 Agent 充当 Dosi 的 skill。 |
| `kodosi devices sleep <computer>` | 让你的另一台电脑进入睡眠。在它被唤醒之前，它的终端会暂停。使用 `kodosi devices keep-awake` 加上 `agents`、`always` 或 `never`，可选择这台电脑何时保持唤醒。 |
| `kodosi devices wake <computer>` | 唤醒你的一台睡眠中的电脑，并等待它上线。`kodosi devices test-wake <computer>` 会让一台电脑进入睡眠，再唤醒它，并保存结果。`kodosi devices list` 会显示 Kodosi 对每台电脑的预期。 |
| `kodosi host` | 独立运行主机进程，使终端在退出应用后继续运行。使用 `kodosi host stop` 可停止后台主机进程。 |

当你正在某个终端里主动输入时，`message`、`input` 和 `keys` 会拒绝执行；当 Agent 正在等待人工回复时，`message` 也会拒绝执行。

## 如果无法连接

- 请确认终端所在的宿主机处于在线状态、Kodosi 正在运行，且该终端仍处于共享状态。
- 新添加的设备可能仍在等待批准；如果好友的身份发生了变化，可能需要在 **好友** 中重新验证。
- 连接中断后，Kodosi 会重新显示当前状态。如果远程终端显示 **离线**，说明当前设备无法连接到服务器，请检查网络连接。Kodosi 会自动尝试重连，你也可以点击 **重试** 立即重连。
- 当宿主机离线时，它的终端会在机器重新上线后自动恢复连接（除非期间已被关闭）。若要从列表中移除离线终端，请点击其上的 `×`：选择 **隐藏，直到它重新上线** 会将其暂时隐藏，选择 **永久关闭** 则会在该电脑重新连接后永久关闭该终端。
- 如果 Kodosi 提示无法确定你的输入是否已送达，请先查看终端屏幕内容，再决定是否重新运行命令。
