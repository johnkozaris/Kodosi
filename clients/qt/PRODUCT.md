# Kodosi for Linux and Windows

[PRODUCT.md](../../PRODUCT.md) has the shared intent and [DESIGN.md](DESIGN.md) the
visual system and shortcuts.

The app looks and behaves like the [Mac app](../macos/PRODUCT.md). Every control works
with the keyboard and screen readers and shows its focus.

Pages and live documents show in Chromium's sandbox. A file that the app cannot show, and
every page and document where the system does not allow that sandbox, as for root, is a
card that opens the file in its app or saves a copy.
